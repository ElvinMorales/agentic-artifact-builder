# Code of Conduct

## Our Standards

This project welcomes contributions from anyone interested in learning about or improving the Agentic Artifact Builder. Participants are expected to:

- Be respectful and constructive in issues, pull requests, and discussions.
- Focus feedback on the work, not the contributor.
- Follow this repository's public-safety rules (see `CONTRIBUTING.md` and `docs/public-safety-checklist.md`) — do not post secrets, private data, or employer-specific content in issues, pull requests, or comments.

Harassment, personal attacks, and other unprofessional conduct will not be tolerated.
